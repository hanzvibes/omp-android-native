# Third-party notices

This project is an Android integration shell and does not currently bundle Oh My Pi, Bun, Termux, or their native artifacts.

Before redistributing runtime components or APKs containing third-party components:
- Include applicable upstream license and copyright notices.
- Review the license of the exact OMP revision and every dependency.
- Review redistribution terms for the selected Bun Android build.
- Review Termux app / bootstrap licensing if using or bundling Termux components.
- Record pinned source revisions and artifact checksums.

References:
- Oh My Pi: https://github.com/can1357/oh-my-pi
- Android / Termux integration: https://github.com/PlayWithG/oh-my-pi-termux
- Bun: https://github.com/oven-sh/bun
- Termux: https://github.com/termux/termux-app
